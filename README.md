# h,x-Diagramm Trainer

Interaktives h,x-Diagramm (Mollier) für die Lüftungs-Vorlesung.

- Schiefwinkliges Mollier-Koordinatensystem mit Isenthalpen (h = const), Isothermen und Nebelisothermen
- Zustandspunkt über Temperatur und relative Feuchte einstellen, Anzeige von x und h
- Klimazonen-Presets: Sommer-Referenztage (Köln, Kopenhagen, Sevilla, Tunis, San Diego, Singapur) und Winter-Norm-Außentemperaturen (Köln, Hamburg, Berlin, München)
- Taupunkt bzw. Reifpunkt (x = const) und Feuchtkugeltemperatur (h = const) grafisch ablesen
- Sättigung über Eis unter 0 °C, Diagrammbereich −20 … 45 °C
- Randmaßstab Δh/Δx (Richtungsmaßstab) mit Pol bei 0 °C

## Starten

`index.html` im Browser öffnen – keine Installation nötig.
